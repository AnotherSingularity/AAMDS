# Incident Handling

Alias for the security playbook in
[`../security/INCIDENT_RESPONSE.md`](../security/INCIDENT_RESPONSE.md).
Operations-facing summary:

1. Snapshot audit + health.
2. Contain (remove offending destination / adapter from active policy).
3. Preserve persistence.
4. Analyse in a replay-mode sandbox.
5. Recover to last-known-good.
6. Report per sponsor process.
